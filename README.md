# Локальная Стройка на WordPress

## Восстановление из Git

В репозитории хранятся активная тема `wp-content/themes/strojka`, скрипты и публичный контент `.local-tools/project-content.json`. Ядро WordPress, плагины, локальная конфигурация, пароли, заявки и рабочая база данных не включены.

Для новой установки в клоне репозитория (нужны PHP с mysqli, MySQL, WP-CLI):

```powershell
php wp-cli.phar core download --skip-content
php wp-cli.phar config create --dbname=strojka_local --dbuser=YOUR_DB_USER --dbpass=YOUR_DB_PASSWORD --dbhost=127.0.0.1
php wp-cli.phar db create
php wp-cli.phar core install --url=http://127.0.0.1:8085 --title=ТУЛАСТРОЙГРУПП --admin_user=YOUR_ADMIN --admin_email=YOUR_EMAIL --prompt=admin_password --skip-email
php wp-cli.phar plugin install advanced-custom-fields --activate
php wp-cli.phar theme activate strojka
php wp-cli.phar eval-file .local-tools/setup-project.php
```

Скачайте `wp-cli.phar` с [официального сайта WP-CLI](https://wp-cli.org/), он не включён в Git. Для клона на этом компьютере используйте отдельное имя базы, чтобы сохранить текущую установку. `setup-project.php` восстанавливает карточки, страницы, меню, контакты и демонстрационные фотографии. Для обновления экспорта после правок в админке: `php wp-cli.phar eval-file .local-tools/export-project.php`. Отдельные скрипты `seed-*` и `design-services.php` использовались при первоначальной сборке; после восстановления контента запускать их не нужно.

## Текущая локальная установка

Под каруселью расположен баннер найма. Его тексты и плашки редактируются в ACF на странице «Вакансии» (`vakansii`). Основное содержимое этой страницы — список вакансий. Кнопка отклика открывает отдельную форму, обращения сохраняются в разделе «Заявки» с пометкой «Отклик на вакансию».

Шапка по макету: логотип, контакты, режим работы, вызов замерщика и основное меню. Контакты, название, подпись, статус инженера и метка сезона меняются в «Внешний вид → Настроить → Контакты компании». Строка СРО выводится только после заполнения соответствующего поля. Баннер первого экрана находится в `template-parts/hero.php`, стили шапки и баннера — в `assets/header.css`.

Блок над каруселью редактируется в разделе «Показатели компании». У каждой карточки есть заголовок, крупный показатель, подзаголовок, описание, значок, выбор шрифта и порядок. Тексты и числа перенесены из предоставленного макета. Опубликованные записи видны на главной; черновики и записи в корзине скрыты.

Проект находится в `C:\Strojka`. PHP и MySQL используются из XAMPP.

Запуск: включите MySQL в XAMPP, затем выполните `powershell -ExecutionPolicy Bypass -File C:\Strojka\start-local.ps1`.

Сайт: http://127.0.0.1:8085/

Админка: http://127.0.0.1:8085/wp-admin/

Данные локального администратора находятся в `local-access.txt`.

Активная тема и её исходники: `wp-content/themes/strojka`. Изменения вносите в эту папку.

Название меняется в настройках WordPress. Телефон и регион — во «Внешний вид → Настроить → Контакты компании».

Карточки карусели: раздел «Услуги» в админке. Добавляйте записи, заполняйте поля ACF и публикуйте. Для удаления с главной переместите запись в корзину или переведите в черновик. Поле «Порядок в карусели» задаёт сортировку: меньшие числа идут первыми. Изображения выбираются из медиатеки; без изображения используется локальная иллюстрация. Список работ заполняется по одному пункту на строку. Список услуг в форме обновляется автоматически.

Навигация: «Внешний вид → Меню → Основное меню». Можно добавлять, удалять и переставлять ссылки. Меню уже назначено области «Основное меню». Поля карточек реализованы в бесплатном ACF, схема находится в `inc/services.php` активной темы.

Карусель поддерживает циклическое переключение кнопками, клавиатурой и свайпом, выбор точки, а также настройку уменьшения анимации. Автоматического переключения нет. Оформление каталога: светлый фон, счётчик, частично видимая следующая карточка. В ACF также доступны зелёная плашка, стоимость, срок и дополнительная строка характеристики. Без стоимости и срока выводятся «По смете» и «По проекту». Демонстрационные фото загружены в медиатеку; источники сохранены в `.local-tools/image-sources.txt`. Шаблон заголовка и карточек — `template-parts/services.php`. Остальные тексты главной находятся в `front-page.php` активной темы.

Форма сохраняет обращения в раздел «Заявки» в админке. Почтовая отправка не настроена. Телефон, регион и описание компании — демонстрационные, их нужно заменить перед публикацией. Страница политики конфиденциальности требует заполнения под реальные реквизиты и процессы компании.

Локальная база: `strojka_local`. Сайт доступен только на этом компьютере. Перед переносом на хостинг настройте отдельного пользователя БД и рабочие учётные данные.
